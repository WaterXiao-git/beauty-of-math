# 剩余 135 个高数 Native 独立实验设计

## 目标

将 `hm-02-01` 至 `hm-14-09` 从旧通用模板替换为 135 个与知识点一一对应的交互实验。验收标准沿用已获认可的“函数与基本图像”15 个页面：数学对象、参数、图形、步骤和观察结论都必须与当前知识点一致，不能只更换标题、颜色或随机数。

## 架构

每个课程模块拥有独立的实验规格文件，规格中的每个知识点都定义唯一公式、可调参数、图形图层、四个教学步骤以及步骤状态。共享层只负责 Native `ExperimentShell`、坐标换算、滑块、SVG 基础图元和 PlayerBar 状态推进，不包含课程结论。渲染注册表为 135 个 ID 分别建立 React 组件入口，并保留已完成的前 15 个显式组件。

## 模块视觉体系

- 极限：数列点列、ε 邻域、左右逼近、无穷远、等价量比值、夹逼带和单调有界过程。
- 连续：局部连接、左右值、间断类型、区间性质、零点/介值/最值验证。
- 导数：差商逼近、割线到切线、单侧导数、运动速度、求导链和线性化误差。
- 中值定理与应用：定理弦线、洛必达比值、符号表、极值/凹凸/曲率、优化模型。
- 积分：原函数族、面积累加、换元映射、分部拆分、反常积分收敛过程及物理应用。
- 微分方程：方向场、解族、初值选择、降阶、振子与实际增长/衰减模型。
- 空间与多元：三维投影、向量运算、平面/直线、曲面等高线、偏导、梯度和约束极值。
- 重积分与场积分：区域剖分、坐标变换、体元、通量/环流及三大积分公式。
- 级数：部分和、判别过程、收敛区间、泰勒逼近和傅里叶谐波叠加。

## 交互要求

每页至少一个连续参数和一个知识点专属状态层。四个步骤必须使用专属动作名称；点击任一步、前后步、播放和重置都会改变画布或参数。右侧“当前观察”与当前步骤及数值同步。所有页面继续套用现有 Native V2 外壳。

## 验收

1. 135 个 ID 均不再注册到 `KnowledgeExperiment` 通用占位组件。
2. 每个 ID 有唯一实验规格签名、公式、控件和四步名称。
3. 每个页面至少包含一种与知识点对应的动态图层。
4. 150 个正式路由保持可访问；AI、课程目录和实验库 ID 不变。
5. TypeScript 构建通过。
