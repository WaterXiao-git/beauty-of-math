# 函数与基本图像 15 个 Native 独立实验设计

## 背景与问题

当前 `hm-01-01` 至 `hm-01-15` 共用同一个函数画布，只通过标题、参数和少量随机种子制造差异。底部“识别对象、调节参数、对比状态、验证结论”也只显示通用文字，没有驱动画布或参数。这不满足“每个知识点单独做一个实验页面”的要求。

本轮仅返工第一模块“函数与基本图像”的 15 个实验，供产品方验收。其余 135 个实验暂时保持现状，待第一模块确认后继续逐模块重做；所有实验完成后才交付客户。

## 已确认的实现原则

1. 15 个知识点分别使用独立 React 实验组件。
2. 每个组件拥有专属数学模型、画布、参数、教学步骤和状态逻辑。
3. 允许复用没有具体数学业务含义的底层组件，例如坐标系、数学标记、滑块、按钮、`ExperimentShell`、`ExperimentCard` 和 `PlayerBar`。
4. 禁止通过同一画布更换标题、颜色、参数或随机种子冒充不同实验。
5. 保持现有 Native Experiment V2 页面外壳、顶栏、侧栏和底栏样式。
6. 底部教学步骤必须真实可用，并与画布状态联动。

## 组件结构

第一模块建立 15 个独立实验组件，统一放在 `client/src/demo/function-basics/`：

| `hm-01-03` | `MonotonicityExperiment.tsx` | 函数的单调性 |
| `hm-01-04` | `ParityExperiment.tsx` | 函数的奇偶性 |
| `hm-01-05` | `PeriodicityExperiment.tsx` | 函数的周期性 |

| `hm-01-07` | `CompositeFunctionExperiment.tsx` | 复合函数 |
| `hm-01-08` | `PiecewiseFunctionExperiment.tsx` | 分段函数 |
| `hm-01-09` | `ParametricEquationExperiment.tsx` | 参数方程 |
| `hm-01-10` | `PolarEquationExperiment.tsx` | 极坐标方程 |
| `hm-01-11` | `ElementaryFunctionsExperiment.tsx` | 基本初等函数 |

共享底层组件放在 `client/src/demo/function-basics/shared/`，仅承载坐标换算、网格、坐标轴、曲线路径、点、投影线和通用控件，不包含任何知识点特有的数学结论。

## 15 个实验的独立内容

### 1. 函数的定义域和值域

- 调节定义域左右端点。
- 曲线只在有效定义域内显示。
- 自变量区间投影到 x 轴，函数值集合投影到 y 轴。
- 区分开区间、闭区间以及无定义区域。
- 四步：选择函数、限定定义域、扫描函数值、确认值域。

### 2. 函数图像

- 联动解析式、数值表、坐标点和完整曲线。
- 用户调整采样点数量或移动当前 x。
- 画布按教学步骤从单点、多个离散点逐渐形成曲线。
- 四步：读取解析式、计算数值表、描出坐标点、连接函数图像。

### 3. 函数的单调性

- 用户拖动研究区间端点。
- 显示函数在区间内的上升或下降趋势。
- 联动割线变化率和导数符号带。
- 四步：选择区间、比较函数值、观察变化率、判断单调性。

### 4. 函数的奇偶性

- 原函数图像关于 y 轴映射。
- 同时比较 `f(-x)`、`f(x)` 和 `-f(x)`。
- 用重合误差判断偶函数、奇函数或非奇非偶函数。
- 四步：选择对称点、计算 `f(-x)`、执行对称映射、判断奇偶性。

### 5. 函数的周期性

- 显示原曲线与横向平移 T 后的副本。
- 用户拖动候选周期 T。
- 实时显示重合程度或周期误差。
- 四步：选择参考点、平移一个周期、比较函数值、确认最小正周期。

### 6. 反函数

- 同时显示原函数、直线 `y=x` 和反函数。
- 点 `(x,y)` 与 `(y,x)` 联动。
- 可切换满足和不满足一一对应的函数，解释反函数存在条件。
- 四步：选择原函数点、交换坐标、关于 `y=x` 对称、验证反函数。

### 7. 复合函数

- 独立展示 `f`、`g` 与 `f∘g`。
- 显示 `x → g(x) → f(g(x))` 输入输出流水线。
- 用户调整 x，并观察三个值同步变化。
- 四步：输入 x、经过内层函数、进入外层函数、生成复合图像。

### 8. 分段函数

- 用户调整分界点和不同区间的函数规则。
- 显示各段颜色、有效区间、空心端点和实心端点。
- 显示分界点左右极限与函数值。
- 四步：划分区间、设置各段规则、处理端点、检查拼接结果。

### 9. 参数方程

- 使用播放参数 t 驱动运动点。
- 联动显示 `x(t)`、`y(t)`、平面轨迹和切向量。
- 可选择圆、椭圆或摆线案例。
- 四步：确定参数、分别计算坐标、描出运动点、形成参数曲线。

### 10. 极坐标方程

- 通过 θ 扫描显示极径 r 和运动点。
- 同时显示极坐标网格、极坐标曲线和直角坐标投影。
- 可选择圆、心形线或玫瑰线案例。
- 四步：确定极角、计算极径、定位极坐标点、扫描完整曲线。

### 11. 基本初等函数

- 提供幂函数、指数函数、对数函数和三角函数的专属函数族选择器。
- 切换后同步展示表达式、定义域、值域、关键点和渐近线。
- 支持选择两类函数进行特征对比。
- 四步：选择函数族、观察定义域、标记关键特征、比较函数类型。

### 12. 函数图像的平移

- 控制水平平移 h 和竖直平移 k。
- 同时显示原图、目标图和平移向量。
- 关键点轨迹与表达式 `f(x-h)+k` 同步变化。
- 四步：选择原图关键点、执行水平平移、执行竖直平移、写出新表达式。

### 13. 函数图像的伸缩

- 分别控制水平尺度和竖直尺度。
- 显示原图、伸缩后图像、坐标网格和关键点映射。
- 区分 `a f(x)` 与 `f(bx)` 的作用方向。
- 四步：选择关键点、竖直伸缩、水平伸缩、比较表达式与坐标。

### 14. 函数图像的翻折

- 分别执行关于 x 轴、y 轴和原点的翻折。
- 显示原图、翻折图和对应点连线。
- 联动展示 `-f(x)`、`f(-x)`、`-f(-x)`。
- 四步：选择翻折方式、映射坐标点、生成翻折图像、验证表达式。

### 15. 参数变化对函数图像的影响

- 使用二次函数 `y=ax²+bx+c` 作为主要参数族。
- 分别调节 a、b、c。
- 同步显示开口、对称轴、顶点、判别式和零点变化。
- 四步：调节 a 观察开口、调节 b 观察对称轴、调节 c 观察竖直位置、综合判断根与图像。

## 教学步骤与 PlayerBar

`PlayerBar` 增加步骤点击回调。每个实验提供自己的四个步骤和确定性的状态补丁：

- 点击步骤：立即应用该步骤需要的参数、显示层和高亮对象。
- 上一步、下一步：切换步骤并同步画布与侧栏。
- 播放：按照实验自己的四个阶段依次执行。
- 暂停：保留当前画布与参数状态。
- 重置：恢复该实验定义的初始参数、第一步和初始高亮。

步骤名称必须描述当前实验的真实教学动作，不再使用统一的“识别对象、调节参数、对比状态、验证结论”。

## 页面数据流

1. 用户打开 `/demo/hm-01-XX`。
2. `DemoPage` 根据实验 ID 从 renderer 注册表取得独立组件。
3. 独立组件初始化自己的数学参数和步骤状态。
4. 参数控件更新实验状态，画布根据状态重新计算图形。
5. PlayerBar 切换步骤时调用该实验的步骤动作。
6. 画布、右侧当前观察和底部步骤保持同步。

## 本轮不做的内容

- 不重做其余 135 个实验。
- 不隐藏或禁用其余 135 个实验。
- 不修改 AI 提问范围。
- 不改变 Native 页面整体视觉模板。
- 不加入图片、语音或公式输入等多模态功能。

## 验收标准

1. `hm-01-01` 至 `hm-01-15` 分别绑定 15 个独立组件。
2. 任意两个实验不能只靠标题、颜色、参数或随机种子区分。
3. 每个实验的数学模型、画布、参数和结论与知识点一致。
4. 每个实验拥有四个专属步骤名称与专属动作。
5. 步骤点击、上一步、下一步、播放、暂停和重置全部真实改变或恢复实验状态。
6. 页面继续使用现有 Native Experiment V2 外壳。
7. 其余 135 个实验不因本轮修改失去现有路由。
8. 代码完成后只执行必要的构建与类型检查，最终视觉和教学效果由产品方验收。
