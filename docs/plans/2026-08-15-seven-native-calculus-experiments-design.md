# 七个高等数学 Native 实验设计

## 目标

为当前高等数学（上册）课程补齐七个完全自研的实验：函数的概念、函数的表示法、函数的性质、数列的极限、连续的概念、连续函数的性质、泰勒公式。实现不得引用已移除的 300 个旧实验源码或数据。

## 统一页面结构

七个实验都直接使用 `ExperimentShell`，并保持当前 Native V2 页面结构：

- 主画布：原创 SVG 数学可视化，不嵌入旧页面。
- 右侧栏：使用 `ExperimentCard` 组织概念、案例、参数和教学判断。
- 底部栏：四个与数学状态真实对应的教学步骤，通过专用 `player` 配置接入。
- 路由：统一使用 `/demo/:id`，由自研实验注册表加载。

## 实验交互

1. **函数的概念**：改变输入集合、对应规则与映射关系，直观看到“每个输入只能对应一个输出”的函数判定。
2. **函数的表示法**：解析式、数值表和函数图像同步更新，展示同一函数的三种表示。
3. **函数的性质**：选择典型函数，并分别观察单调性、奇偶性、周期性和有界性。
4. **数列的极限**：调整误差 `ε`，观察数列尾项何时全部进入误差带，并得到对应的 `N`。
5. **连续的概念**：移动考察点并切换连续、可去、跳跃、无穷间断案例，对比左右极限和函数值。
6. **连续函数的性质**：切换零点定理、介值定理、最值定理，展示条件与结论之间的关系。
7. **泰勒公式**：调整展开阶数和展开中心，对比原函数、泰勒多项式与余项误差。

## 数据与注册

- 在 `config/owned-experiments.json` 中增加七条 `self-developed` 实验元数据。
- 由现有生成器同步生成前端 catalog 和后端 Agent registry。
- 在课程知识点上显式配置 `rendererId`，保证知识地图和“浏览全部实验”使用同一个实验来源。
- 更新产品范围门禁，使正式范围固定为 15 个自研实验。

## 验收标准

- 七个知识点均出现“进入演示”，且打开对应 Native 页面。
- `/experiments` 只列出 15 个自研实验，不出现旧 300 实验数据。
- 前端注册表与后端 Agent registry 一致。
- 客户端测试、服务端测试、范围检查和生产构建全部通过。
