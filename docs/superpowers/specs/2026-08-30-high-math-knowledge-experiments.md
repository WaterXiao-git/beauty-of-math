# 高等数学十四模块知识点实验设计

## 范围

- 当前版本只发布高等数学，不恢复其他课程与旧版 300 个实验。
- 课程目录采用客户文档《实验的完善与补充需求》中的十四个模块。
- 文档列出的 150 个知识点全部成为独立目录叶子、独立 `/demo/:id` 地址和独立实验页面。
- 只保留文本 AI 提问，不恢复图片、语音、公式输入、讲解音频或旧实验资源。

## 页面与数据设计

- 课程、知识地图、实验库和 AI 匹配共同读取同一份高等数学知识点清单。
- 每个知识点记录模块、标题、简介、学习目标、先修关系、实验类型和自研 renderer ID。
- 页面统一使用 `ExperimentShell`、`ExperimentCard` 与 `PlayerBar`。
- 同类知识点共用 Native SVG/HTML 绘图能力，但每个知识点拥有独立参数、观察目标、步骤和结论。
- 已有专用实验在语义完全匹配时继续使用；其余知识点进入统一 Native 知识实验渲染器。

## 验收标准

- 仅有一门高等数学课程，共十四个模块、150 个唯一知识点。
- 每个知识点均在自研实验清单中有唯一条目，并能通过 `/demo/:id` 打开 Native 页面。
- 目录、知识地图、实验库、前端 catalog 与后端 AI registry 数量和 ID 一致。
- 正式构建与交付物不包含旧 300 实验及其资源。
