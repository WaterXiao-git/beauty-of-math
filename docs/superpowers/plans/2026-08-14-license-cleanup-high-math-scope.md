# Licensed Experiment Cleanup and Higher Mathematics Scope Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 从后续源码、构建结果和交付物中彻底移除存在许可证风险的旧 300 个实验及其派生资源，只保留高等数学（上册）四章、8 个自研正式实验、通用 Experiment V2 外壳和通用 AI 临时实验能力。

**Architecture:** 先用一个不含 React 代码的正式实验清单定义 8 个允许交付的实验，再生成前端目录和后端路由注册表；前端知识点只能显式绑定清单中的 renderer，后端 Agent 只能返回清单中的 ID。完成引用切换后，删除旧实验、Legacy Runtime、讲解音频、旧搜索/CRUD/迁移工具，并由只读范围检查器阻止它们重新进入源码和构建产物。

**Tech Stack:** React 19、TypeScript、React Router、Vite、Vitest、Node.js、Express、tsx、Node Test Runner、DeepSeek/Qwen OpenAI-Compatible API、PowerShell、Git。

- [ ] **Step 4: 编写确定性生成器**

`scripts/generate-owned-experiment-registries.mjs` 必须：

1. 读取 `config/owned-experiments.json`；
2. 拒绝重复 ID、非 `/demo/<id>` 路径、非 `self-developed` 来源和非 8 项数据；
3. 按 ID 排序生成前后端 `.generated.ts`；
4. 支持 `--check`，只比较文件内容，不写文件；
5. 生成内容顶部包含 `// Generated by scripts/generate-owned-experiment-registries.mjs. Do not edit.`。

前端生成类型应为：

```ts
export interface OwnedExperimentCatalogEntry {
  id: string
  title: string
  path: string
  knowledgePointId: string
  description: string
  topics: readonly string[]
  ownership: 'self-developed'
}

export type OwnedExperimentId = typeof OWNED_EXPERIMENT_CATALOG[number]['id']
```

`OWNED_EXPERIMENT_CATALOG` 的实际数组内容必须由上一步完整 JSON 逐项生成；生成文件不能用省略号、占位注释或手工补录。

后端生成结构在以上字段基础上增加 `semanticEnabled`、`aliases`、`strongPhrases`、`keywords` 和 `supportedIntents`；这些路由词由清单字段确定性生成，不调用 LLM。
